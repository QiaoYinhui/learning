# 工作记录

记录工作日志、项目档案和会议纪要。

## 分类

### 工作日志 (`logs/`)
按年月组织的工作日志，记录每天的工作内容和进展

目录结构：`logs/YYYY/MM/YYYY-MM-DD.md`

### 项目档案 (`projects/`)
每个项目一个子目录，包含：
- `README.md` - 项目概述
- `design.md` - 设计文档
- `retrospective.md` - 复盘总结
- 其他相关文档

### 会议纪要 (`meetings/`)
重要会议的纪要和决策记录

## 命名规范

- 工作日志：`YYYY-MM-DD.md`（如 `2026-11-03.md`）
- 项目文档：放在 `[project-name]/` 目录下
- 会议纪要：`YYYY-MM-DD-[会议主题].md`

## 使用建议

1. 每日记录：养成写工作日志的习惯
2. 项目复盘：项目结束后及时总结
3. 决策记录：重要决策要记录背景和思考过程
4. 定期归档：完成的项目移到归档区

# 技能树管理

可视化个人能力成长路径，规划学习方向。

## 核心文件

### 技能清单 (`skill-tree.md`)
列出掌握的技能及熟练度评估

### 学习计划 (`learning-plans/`)
阶段性的学习计划和目标

## 技能评估标准

- ⭐⭐⭐⭐⭐ **专家** - 能解决复杂问题，可以教别人
- ⭐⭐⭐⭐ **熟练** - 能独立完成复杂任务
- ⭐⭐⭐ **掌握** - 能完成日常工作
- ⭐⭐ **了解** - 知道基本概念，需要查文档
- ⭐ **入门** - 刚开始学习

## 使用建议

1. 定期评估：每季度更新一次技能树
2. 设定目标：明确短期和长期的学习方向
3. 记录进度：跟踪学习进展
4. 平衡发展：T 型人才 - 广度和深度并重

# 学习经验

记录学习过程中的心得、笔记和总结。

## 分类

### 技术学习 (`tech/`)
- **programming/** - 编程语言（Python、JavaScript、Go 等）
- **frameworks/** - 框架工具（React、Vue、Django 等）
- **ai-ml/** - AI/机器学习（深度学习、NLP、CV 等）
- **devops/** - 运维部署（Docker、K8s、CI/CD 等）

### 课程笔记 (`courses/`)
在线课程、培训课程的笔记和作业

### 读书笔记 (`books/`)
技术书籍、管理书籍等的阅读笔记

### 论文阅读 (`papers/`)
学术论文的阅读笔记和理解

## 命名规范

学习笔记文件命名格式：`[主题]-[日期].md`

示例：
- `react-hooks-2026-11-03.md`
- `python-async-2026-11-05.md`

## 使用建议

1. 及时记录：学习后尽快整理笔记
2. 结构化：使用模板保持格式统一
3. 定期回顾：标记需要复习的内容
4. 实践结合：记录代码示例和实践案例

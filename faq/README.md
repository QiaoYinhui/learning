# 问题解答库

记录常见问题的解决方案，避免重复踩坑。

## 分类

### 编程问题 (`programming/`)
编程语言、框架、库的使用问题和解决方案

### 工具使用问题 (`tools/`)
开发工具、软件的使用技巧和问题排查

### 故障排查 (`troubleshooting/`)
系统故障、环境配置、部署问题的排查和解决

## 文档格式

```markdown
# [问题简述]

## 问题描述
[详细描述遇到的问题]

## 错误信息
[相关的错误日志或提示信息]

## 解决方案
[解决步骤]

## 原因分析
[问题的根本原因]

## 预防措施
[如何避免类似问题再次发生]

## 参考资料
[相关链接或文档]
```

## 使用建议

1. 及时记录：解决问题后立即记录
2. 描述清晰：问题描述要详细，便于后续查找
3. 标注环境：记录操作系统、版本号等环境信息
4. 定期整理：合并相似问题，删除过时内容

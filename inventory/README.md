# 文档位置清单

记录电脑和云端重要文件的位置，便于快速定位。

## 文件索引

### 本地文件 (`local-files.md`)
本地电脑上重要文件的路径索引

### 云存储 (`cloud-storage.md`)
云端存储资料的位置索引（iCloud、Google Drive、百度网盘等）

### 按类别分类 (`by-category/`)
- **work-docs.md** - 工作文档位置
- **study-materials.md** - 学习资料位置
- **personal-files.md** - 个人文件位置

## 使用建议

1. 定期更新：新增重要文件时及时更新索引
2. 路径准确：确保记录的路径是正确的
3. 分类清晰：按用途或项目分类
4. 保护隐私：不要记录敏感信息（密码、密钥等）

## 示例格式

```markdown
## 工作文档

| 文件/目录 | 路径 | 说明 |
|----------|------|------|
| 项目A资料 | ~/Documents/Projects/ProjectA | 项目相关文档 |
| 周报模板 | ~/Templates/weekly-report.docx | 每周工作汇报 |
```

# 思考与复盘

培养反思习惯，提炼个人方法论。

## 分类

### 周复盘 (`weekly/`)
每周的回顾和总结，命名格式：`YYYY-WXX.md`（如 `2026-W44.md`）

### 月复盘 (`monthly/`)
每月的回顾和总结，命名格式：`YYYY-MM.md`（如 `2026-11.md`）

### 年复盘 (`yearly/`)
每年的回顾和总结，命名格式：`YYYY.md`（如 `2026.md`）

### 决策记录 (`decisions/`)
重要决策的背景、选项和结果分析

## 复盘框架

### 周复盘框架
1. 本周完成了什么？
2. 遇到了什么问题？
3. 学到了什么新东西？
4. 下周计划做什么？
5. 有什么需要改进的？

### 月复盘框架
1. 本月目标完成情况
2. 关键成果和亮点
3. 遇到的挑战和解决方案
4. 能力提升情况
5. 下月目标和计划

## 使用建议

1. 固定时间：每周日/月末安排固定时间复盘
2. 诚实面对：客观记录，不回避问题
3. 提炼方法：从经验中总结可复用的方法
4. 持续改进：基于复盘结果调整行动

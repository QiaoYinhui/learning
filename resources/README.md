# 资源收藏

收集和整理有价值的参考资料、工具和模板。

## 分类

### 文章收藏 (`articles/`)
技术文章、博客、教程等的收藏和笔记

### 工具推荐 (`tools/`)
好用的工具、软件、服务的介绍和使用心得

### 视频笔记 (`videos/`)
技术视频、演讲、教程的笔记和总结

### 模板文件 (`templates/`)
可复用的文档模板：
- `learning-note.md` - 学习笔记模板
- `project-summary.md` - 项目总结模板
- `weekly-review.md` - 周复盘模板

## 命名规范

- 文章收藏：`[来源]-[标题简写].md`
- 工具推荐：`[工具名称].md`
- 视频笔记：`[视频标题简写]-notes.md`

## 使用建议

1. 及时收藏：看到好内容及时保存
2. 添加笔记：不只是收藏，要写下自己的理解
3. 定期整理：删除过时的内容
4. 分类清晰：选择合适的分类便于查找

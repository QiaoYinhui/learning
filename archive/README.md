# 归档区

存放已完成、过时或不再活跃的内容。

## 归档原则

1. **已完成的项目**：结束的项目文档
2. **过时内容**：不再适用的技术笔记
3. **历史资料**：需要保留但不再更新的内容

## 归档结构

可以按年份或类别组织：
- `archive/2025/` - 2025 年的归档
- `archive/old-projects/` - 旧项目归档
- `archive/legacy-notes/` - 过时笔记

## 使用建议

1. 定期整理：每季度检查一次，将过时内容移到归档区
2. 保留索引：归档内容仍可在 INDEX.md 中查找
3. 标注状态：在文档头部标注 `[已归档]`
4. 不删除：归档不等于删除，保留参考价值
